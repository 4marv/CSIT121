Reflection

Throughout this entire course, I learned the fundamentals of web development, from learning how to build and structure web pages with HTML and CSS, to integrating responsive web design into my web pages. When I first started this course, I thought that it would be some what of a cake walk, with obviously some roadblocks ahead. That was somewhat the case, but it was much more difficult then I thought it would be. I already had past experience with web development from a few years back, so I regained my web design skills pretty quickly. However, there was also a lot ahead of me that was completely new to me, and I had to take my time to learn it.

For this specific project, it was challenging trying to come up with a design for the website that I personally liked. I ended up going with a "minimal" kind of aesthetic with the monochrome colors. Another challenge that I had was testing the website. I tested my website with both the normal live preview on Visual Basic, and another extension called "Mobile Live Preview", which simulates how a web page would look like on a mobile device. I had some difficulties making it work, but I used skills I learned from responsive web deisgn to make it work for all devices. I also added some animations to make the website feel more interactive, with some help from a tutorial as I am still not used to doing it.

Overall, this course helped me build upon the foundation I already previously had on webpage development. I now have a better understanding on how websites are stuctured, styled, and published online, and also how important it is to make your website both compatible and accessible to real users.
